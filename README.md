# پروژه بازی حدس اعداد با پایتون

## توضیحات
در این بازی، برنامه یک عدد تصادفی بین 1 تا 100 انتخاب می‌کند و کاربر حداکثر 5 فرصت دارد تا آن را حدس بزند.

## امکانات
- انتخاب عدد تصادفی بین 1 تا 100
- حداکثر 5 تلاش معتبر
- نمایش شماره تلاش و فرصت‌های باقی‌مانده
- راهنمای بزرگ‌تر یا کوچک‌تر بودن عدد مخفی
- راهنمای نزدیک یا دور بودن حدس
- تعیین رتبه بر اساس تعداد تلاش‌ها
- نمایش عدد مخفی در صورت باخت
- امکان شروع بازی مجدد
- بررسی ورودی نامعتبر؛ ورودی نامعتبر از فرصت‌ها کم نمی‌کند

## پیش‌نیاز
Python 3

این پروژه فقط از کتابخانه‌های استاندارد پایتون استفاده می‌کند و نصب کتابخانه اضافی لازم ندارد.

## روش اجرا
در ترمینال، وارد پوشه پروژه شوید و دستور زیر را اجرا کنید:

```bash
python guess_number.py
```

در بعضی سیستم‌ها ممکن است لازم باشد از دستور زیر استفاده کنید:

```bash
python3 guess_number.py
```
